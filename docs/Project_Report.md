# 32-bit 5-Stage Pipelined RISC-V CPU

## Project Overview

Designed and implemented a 32-bit 5-stage pipelined RISC-V processor using Verilog HDL.

## Frontend VLSI Flow

✔ RTL Design

✔ Testbench Development

✔ Functional Simulation (Icarus Verilog)

✔ Waveform Verification (GTKWave)

✔ RTL Linting (Verilator)

✔ RTL Synthesis (Yosys)

✔ Gate-Level Netlist Generation

✔ Gate-Level Simulation
